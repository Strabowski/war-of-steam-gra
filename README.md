# War of Steam – gra (pliki dla launchera)

## Pobierz launcher

**[WarOfSteamLauncher.zip](https://github.com/Strabowski/war-of-steam-gra/raw/main/WarOfSteamLauncher.zip)** (Windows, ok. 38 MB)

1. Rozpakuj zip do dowolnego folderu (np. `C:\Games\WarOfSteam`).
2. Uruchom `WarOfSteamLauncher.exe` – sam pobierze i będzie aktualizował grę.
3. Plik nie jest podpisany: jeśli Windows pokaże ostrzeżenie SmartScreen, kliknij **Więcej informacji → Uruchom mimo to**.

Ten folder pobiera **WarOfSteamLauncher.exe** – nie trzeba tu niczego ściągać ręcznie.
Kod gry jest w prywatnym repozytorium. Aktualna wersja: `514c2de` (2026-11-04 20:24), protokół sieci 28, Godot 4.7.2.

Serwer dedykowany (Ubuntu): `curl -fsSL https://raw.githubusercontent.com/Strabowski/war-of-steam-gra/main/serwer/instaluj.sh | sudo bash`
